## 1. 결론 요약

1. **현재 화면의 중심 지표가 자동으로 수집되지 않는다.** 첫 차트("외국인 선물과 지수")와 판정 로직의 핵심 입력은 외국인 선물 순매매다. 그런데 키움 API(OCX·REST)에는 이 경로가 없다. 지금은 영웅문 0780 수동 입력에만 의존한다.
2. **키움으로 자동 수집 가능한 것만으로도 파생 흐름은 충분히 볼 수 있다.**
   - 선물: 실시간 시세·미결제약정·베이시스
   - 옵션: 실시간 시세·미결제·내재변동성·델타
   - 옵션 투자자별 행사가 수량(opt50038)
   - 프로그램 매매와 현물 투자자 수급(REST)
   - 풋콜비율·변동성 추이(TR)
3. 따라서 화면을 다음 세 축으로 재구성한다.
   - **"자동 수집 지표" 중심**: 선물 OI 4분면, 베이시스·프로그램, 옵션 델타 환산 수급, 옵션 OI 벽, IV·풋콜비율
   - **"수동 입력"은 보조**: 0780 선물 수급
   - **"검증 기록"**: 각 신호 이후 5·15·30·60분 수익률
4. 투자자별 **보유 포지션 수준**은 키움 데이터로 알 수 없다(opt50039 사용 불가, opt50038 누적은 미결제약정 초과). 화면은 "오늘의 변화"와 "시장 전체 구조"에 집중한다.

## 3. 추가·변경 제안 (우선순위)

### P1 — 이미 받는 데이터로 바로 가능, 가치 높음

1. **옵션 델타 환산 수급 (투자자별)**
   - 계산: `opt50038` 당일 순매수 × 행사가별 델타. 결과는 선물 계약 상당이다.
   - 델타는 두 방식을 함께 표시한다: `opt50021/22` 델타(% 단위 확인됨)와 IV 기반 BS.
   - 22:40 실조회 예: 외국인 -211(BS) ~ -381(키움 델타), 개인 +37 ~ +67, 금융투자 +3 ~ +16.
   - 5분마다 다시 조회하므로 직전 대비 변화(5·15분)도 낸다.
   - 콜 매수/매도, 풋 매수/매도로 분해해 "방향 베팅"과 "변동성 매도"를 구분한다.
   - 0780 선물 값이 있으면 **선물+옵션 합산 델타 변화**를 표시한다. 없으면 옵션분만 표시하고 "선물 미입력"으로 명시한다.
2. **선물 미결제약정 4분면**
   - 실시간 가격과 OI의 5·15분 변화로 신규 매수(↑↑), 신규 매도(↓↑), 숏커버(↑↓), 롱청산(↓↓)을 판정한다.
   - 투자자 구분 없이 시장 전체의 "새 포지션이 쌓이는 방향"을 보여 준다. 완전 자동 수집이다.
3. **옵션 OI 벽·최대 고통 지점**
   - 전 행사가 OI(`opt50021/22`, 5분 갱신)로 계산한다.
   - 지수 위 최대 콜 OI(저항 후보), 아래 최대 풋 OI(지지 후보), max pain을 낸다.
   - 만기 주(잔존 5영업일 이하)에는 강조한다.
4. **IV·스큐·풋콜비율**
   - ATM IV의 수준과 5·15분 변화를 보인다.
   - 스큐는 ATM 아래 풋 IV − 위 콜 IV다.
   - 풋콜비율은 거래량·OI 기준 두 가지를 보이고, `opt50018` 장중 추이도 표시한다.
   - "하락 대비 수요(풋 IV↑·스큐↑)"를 지수 방향과 따로 보여 준다.
5. **판정 로직 재구성**
   - 현재 판정은 외국인 선물 5분 변화가 핵심이다. 이를 자동 지표 묶음으로 바꾼다: 선물 OI 4분면, 비차익 프로그램, 베이시스 괴리, 옵션 델타 수급.
   - 수동 0780 값은 들어오면 보조 근거로만 추가한다.
   - 각 구성요소의 방향과 기여도를 그대로 보여 준다. 숨겨진 점수를 만들지 않는다.

### P2 — 추가 수집 필요

6. **선물 호가 순매수잔량**(실시간 `선물호가잔량`): 단기 압력 보조 지표.
7. **재시작 복구**: `opt50062`(선물 OI 분봉)로 앱 재시작 전 구간을 채워 5·15분 계산의 공백을 줄인다.
8. **변동성 레짐**(`opt50024` 일별): 대표 IV와 역사적 변동성의 차이로 그날 신호 임계값의 크기를 조정할 근거를 마련한다.

### P3 — 검증 (예측에 쓰려면 필수)

9. **신호별 성과 집계**
   - 기존 관측 기록(5·15·30·60분 수익률)을 신호 종류별로 집계한다: 적중률, 평균 수익, 표본 수.
   - 표본이 30건 미만이면 "검증 부족"으로 표시한다.
10. **일 마감 기록**
    - 15:45 이후 그날의 지표 요약(옵션 델타 수급, OI 4분면 누적, 0780 마감값, 지수 종가)을 일별 표로 쌓는다.
    - 다음 날 시가·종가 방향과의 관계를 본다.
11. 임계값(현재 `rules`)은 이 기록으로만 조정한다. 과거 수익률에 맞춰 최적화했다고 표시하지 않는다.

### 하지 않을 것

- 투자자별 보유 포지션 수준 추정. opt50038 누적은 보유량이 아니고, 키움에는 다른 근거가 없다. 기존 "추정 포지션 CSV" 패널은 증권사 추정 자료를 직접 넣을 때만 쓴다.
- 딜러 감마 노출(GEX) 단정. 누가 매도 측인지 키움 데이터로 알 수 없다. 넣는다면 "가정" 표시를 붙인 참고값으로만 넣는다.
- 영웅문 화면 자동 캡처나 매크로 수집.

## 4. 화면 배치 제안

1. **상단 판정 바**: 자동 지표 4개의 방향(▲▼·)과 갱신 시각, 수동 0780 반영 여부.
2. **선물 패널**: 지수·선물 가격, OI 4분면 타임라인, 베이시스(시장−이론), 비차익 프로그램.
3. **옵션 수급 패널**: 투자자별 델타 환산 당일·5분 변화(콜/풋 분해), 선물+옵션 합산(0780 있을 때).
4. **옵션 구조 패널**: 행사가별 OI 벽과 지수 위치, max pain, IV·스큐·풋콜비율 추이.
5. **현물 패널**: 외국인·기관 현물, 관심종목(기존).
6. **검증 패널**: 신호별 이후 수익률 집계와 표본 수.
7. **데이터 상태**: 각 지표의 출처·수신 시각·자동/수동 구분(기존 수신 상태 확장).

## 5. 구현 순서 제안

1. P1-1 옵션 델타 환산 + P1-3 OI 벽. `opt50021/22`를 5분 주기 조회에 추가한다(회차당 +2건).
2. P1-2 OI 4분면 + P1-5 판정 재구성.
3. P1-4 IV·스큐·풋콜비율.
4. P3 검증 집계와 일 마감 기록.
5. P2 항목.

각 단계마다 다음 순서를 지킨다: 오프라인 테스트 → 데이터 사본 화면 확인 → 장중 실수집 확인.
