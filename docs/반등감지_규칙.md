# 실시간 반등 감지 — 2026-10-30

기존 5분 동조 판정과 별도로 `rebound-1` 관측 규칙을 추가했다. 설정·API 자격증명 변경 없이 저장된 입력과 기존 수집 자료만 사용한다.

## 조건

1. 조짐: 외국인 일반선물 최근 5분 순매수 >0계약 + KOSPI200 최근 5분 상승률 ≥ 기존 price_5m_pct(현재 0.08%). 기존 외국인 300계약 기준은 동조 판정용으로 유지하며 조짐 감지에는 적용하지 않는다.
2. 확인: 1차 + 비차익 최근 약5분 분당 순매매가 순매수·보합이거나 앞선 약10분 순매도 속도보다 완화 + 시장−이론 베이시스 5분 변화 ≥ 기존 basis_change_5m(현재 0.05p) + 외국인 선물 최근5분과 그 앞10분 모두 순매수.
3. 지속성: 2차 + 외국인 현물 순매도 완화·순매수 + 현재 KOSPI200이 최근5분을 제외한 앞선10분의 최고 유효 관측값 초과.

확인·지속성 단계는 해당 조건 묶음이 confirm_min(현재3분) 유지되고 새 원자료 시각 조합이 3회 이상 관측되어야 확정한다. 조짐만으로 확인 알림을 만들지 않는다. 확인·지속성 확정은 기존 관측 기록·화면 알림(알림음이 켜진 경우 소리)과 5·15·30·60분 후 평가에 연결했다. 기존 cooldown_min(15분)을 종류별로 적용한다. 단계가 바뀌거나 조건 미충족·자료 부족·장외가 되면 지속 시간을 초기화한다. 주문·외부 메시지 전송은 없다.

각 조건은 충족/미충족/자료 부족으로 표시한다. 5·15분 수신 상태는 현재 자료 신선도와 과거 구간 관측 부족을 구분한다. 반등 방향의 원인이나 외국인 신규/청산은 식별하지 않는다. 당일 배경은 앞서 추가한 관측값 표시를 사용한다.

중간의 오래된 캐시 스냅숏을 신규 시장 관측으로 취급하지 않는다. 유효 관측 사이 공백은 기존 max_gap_sec(150초) 이하여야 하며, 기준점 부족·현재 지연·수동 입력·날짜/월물 차이는 여전히 계산을 보류한다. 동일 LS 제공처의 사후 복구 자료는 기존 동조 계산에서 사용할 수 있고 mixed 출처 기록을 유지한다. 매매 속도 비교는 동일 출처·집계 범위·자료 종류 검증을 계속 적용한다.
