# 시간 구간별 흐름 표시 — 2026-10-30

## 반영 범위

- 상단에 최근 5분 판정과 실제 사용한 지표·기준·결과를 표시한다. 당일 배경과 최근 15분 맥락은 별도 영역이다.
- `flow_explanation.py`는 기존 엔진이 계산한 축 방향을 받아 화면용 설명만 만든다. 기존 임계값·판정 라벨·관측 이벤트 종류·확인 시간·쿨다운은 유지한다.
- 화면용 `동조 조건 미충족`과 기존 기록용 `혼조 / 변화 관찰`은 구분한다. 방향 엇갈림·기준 미달·자료 부족을 설명한다.
- 현물 측 축은 기존 우선순위(비차익 → 전체 프로그램 → 외국인 현물)의 실제 사용 항목을 표시한다. 출처와 현재 원자료 시각은 항목의 툴팁에 있다.
- 당일 선물 전일 대비·현물 및 일반선물 당일 누적·코스피 상승 종목 비율을 관측값으로 표시한다. 새 '강한 하락' 등급을 만들지 않는다.
- 순매매 속도는 최근 약 5분과 그 앞 약 10분을 공통 경계점으로 나눠 실제 원자료 시간 차로 계산한다. 동일 출처·scope·quality와 시각 연속성을 확인한다. 공백·지연·수동 입력·기준 시각 부족은 비교 불가다.
- 순매도 지속과 속도 완화는 동시에 표시할 수 있다. 부동소수점 오차만 같은 속도로 처리하며 경제적 의미의 신규 임계값은 추가하지 않는다.
- 베이시스 수준과 5분 변화를 따로 표시한다. 베이시스·15분 가격·미결제는 상단 동조 판정의 직접 조건이 아니라고 안내한다.
- 시장 전체 미결제로 외국인의 신규/청산이나 가격 주도 주체를 식별하지 않는다. 자동 반등 확인 규칙은 추가하지 않았다.
- 설명이 없는 기존 저장본은 설명 자료 없음으로 표시한다. 마감 복기에서는 장중 관측의 계산 시각을 확인하도록 안내하고 마감값으로 5·15분 구간을 채우지 않는다.
