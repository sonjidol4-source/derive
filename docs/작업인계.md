## 8. 현재 실행 환경의 제한

마지막 실행 환경은 작업 폴더 내 쓰기는 가능하지만 네트워크와 프로세스 조회가 제한됐다.

- `127.0.0.1:8765` 접속도 소켓 접근 권한 오류가 발생했다.
- 네트워크 권한 요청 결과는 허용되지 않았다.
- `Get-CimInstance Win32_Process`도 접근이 차단돼 점검기를 직접 종료하지 못했다.
- 따라서 사용자가 점검 실행창을 닫고 업데이트를 마친 후 직접 실행하도록 안내한 상태다.

다음 세션은 권한이 다를 수 있으므로 현재 상태를 확인한다. 제한을 우회해 다른 앱이나 실행 경로로 같은 접근을 시도하지 않는다. 제한이 계속되면 가능한 파일 분석·수정·오프라인 검증을 진행하고 실제 접속 검증이 남았다고 명시한다.
