# 한투(KIS) KRX 야간선물 연결

작성: 2026-10-22 밤(한국시간). 기존 수집기(`app.py`)·대시보드·설정 파일은 수정하지 않았고, 새 파일만 추가했다. `AGENTS.md`·`docs/작업인계.md`에도 아직 반영하지 않았다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `한투_야간확인.bat` | 근월물 체결(H0MFCNT0)·호가(H0MFASP0)를 3분 받아 보고 `data/한투_야간확인.txt`에 결과를 남긴다. 키가 없으면 등록부터 한다 |
| `한투_키등록.bat` | 앱키·앱시크릿 등록·교체(입력은 화면에 안 보임). 웹소켓 접속키 발급으로 키를 확인한다 |
| `한투_야간기록.bat` | 06:05까지 체결을 받아 1분봉 `data/kis_night/{기준일}_{코드}_1m.csv`와 최신 요약 `data/kis_night_latest.json`을 저장한다. 기록하는 동안 절전 진입을 막고, 끝나면 해제한다 |
| `kis_api.py` | 접속키 발급, 근월물 코드 선택, 웹소켓 수신, 메시지 해석, 1분봉 계산 |
| `kis_night.py` | 위 세 실행 파일의 본체(`setup`·`check`·`record`) |
| `tests/test_kis_api.py` | 단위 테스트(네트워크 없음). `websockets`가 설치돼 있으면 로컬 소켓 왕복도 확인한다 |

처음 실행 때 `websocket-client`가 없으면 `kis_night.py`가 같은 파이썬에 설치한다(`pip install websocket-client`).

## 키 보관

- 키는 `secrets\kis_openapi.json`(LS 키 파일과 같은 폴더)에 `app_key`·`app_secret`으로만 저장한다. 화면·로그·보고서에 출력하거나 복사하지 않는다.
- 웹소켓 접속키(approval_key)는 실행할 때마다 새로 받고 저장하지 않는다.
- 발급할 때마다 알림톡이 가는 REST 접근토큰(`/oauth2/tokenP`)은 쓰지 않는다.

## 근거

- 한국투자증권 공식 저장소 `koreainvestment/open-trading-api`의 `examples_llm/domestic_futureoption`에서 다음을 확인했다.
  - KRX야간선물 실시간종목체결 `H0MFCNT0`(49열), 실시간호가 `H0MFASP0`(38열)과 각 컬럼 순서.
  - 접속키 발급 `POST /oauth2/Approval`, 웹소켓 주소 `ws://ops.koreainvestment.com:21000`(예제 경로 `/tryitout`).
  - `PINGPONG`을 받으면 같은 내용으로 pong을 돌려준다.
- 근월물은 지수선물옵션 종목정보파일 `fo_idx_code_mts.mst`의 `F YYYYMM` 월물 가운데, 만기일이 야간장 기준일보다 뒤인 첫 월물로 고른다.
  - 만기일 저녁 장은 다음 월물로 넘어간다.
  - 종목정보파일을 못 받으면 `A01`+연도 끝자리+월 규칙값을 쓴다. 2026-10-22 기준으로 `A01612`다.
- 외부 공개 프로젝트(codeyoma/krx-quant 이슈 #264)가 2026-10-21 23:31에 `A01612`로 두 TR 수신을 기록했다.
- 6자리 코드가 거절되면 LS 형식(`A016C000`)으로 한 번 더 구독한다.

## 확인한 범위와 미확인

- **구현·테스트:** 로컬 가짜 서버로 전체 흐름을 확인했다. 키 등록, 접속키, 종목정보파일, 구독, 체결·호가·PINGPONG 수신, 보고서·1분봉·요약 저장까지다. 단위 테스트는 22개 통과했다.
- **미확인:**
  - 이 PC에서 실제 한투 서버 수신.
  - 야간 '전일 대비'의 기준값. 보고서의 '주간 종가 대조' 줄이 LS 주간 마지막 값과 비교한다.
  - 거래대금(`acml_tr_pbmn`) 단위.
  - 미결제 증감(`otst_stpl_qty_icdc`)의 기준 시점.
- 야간 투자자별 수급은 이 TR에 없다.

## 데이터 형식

`data/kis_night_latest.json`의 필드:

- 기본 항목: `source`, `status`, `session_day`(야간장이 시작된 날짜), `code`, `trades`, `quotes`, `first_trade`, `last_trade`
- `values`: `fut_price`, `change`, `change_pct`, `base_price`(=현재가−전일대비), `fut_open/high/low`, `volume`, `oi`, `oi_change`, `basis`, `basis_theory`, `strength`, `buy_vol`, `sell_vol`, `ask1`, `bid1` 등
- `session`: `open`, `high`, `low`, `close`, `bars`. 프로그램이 켜져 있던 구간의 체결만 반영한다.

1분봉 CSV 열은 `time,open,high,low,close,volume,buy_vol,sell_vol,oi,strength`다.

- 첫 봉의 매수·매도 수량은 기준값이 없어 비운다.
- 기록을 중간에 다시 켜면 같은 분이 두 줄 생길 수 있다.
